# 🎯 BOTTTLE SHOOTER Bottle Shooter

A responsive browser arcade game where you shoot every bottle before your bullets run out.

## Features
- Progressive rounds with increasing difficulty
- Limited bullets and accuracy bonus
- Moving targets in later rounds
- Mouse, touch and pointer controls
- Recoil, shot trails, hit particles and sound
- Persistent best score with localStorage
- No external assets or backend
- GitHub Pages ready

## Controls
Mouse/touch: aim and fire · Ⅱ: pause · 🔊: sound · RESTART: Round 1
